128×64 グレースケール命令エミュレーター

ブラウザー内で動作します。ディスプレイは128×64ピクセル、各ピクセルは0〜Fの16階調です。

ディスプレイ

座標: x=1〜128 / y=1〜64 選択画素: (1, 1) = 0

このディスプレイはプログラムからのみ変更できます。画面上のクリックやドラッグでは画素を書き換えません。

クリックキー

clicking-key name は最後に押したキーを変数に保存します。画面を描画する機能ではありません。

プログラム

待機中

命令は1行に1つ。命令名・ラベル名・変数名は大文字小文字を区別しません。値には空白を含む文字列（引用符付き）も指定できます。

変数

  • 変数はまだありません。

実行ログ

    命令一覧・仕様
    • lavel reset / label reset: ラベルを定義します。
    • goto reset: 指定ラベルへ移動します。
    • if input1 input2 reset: 2つの変数の値が等しい場合、指定ラベルへ移動します。
    • else input1 input2 reset: 2つの変数の値が異なる場合、指定ラベルへ移動します（通常のif-elseブロックではありません）。
    • display var 1 1: 画面のx=1、y=1の画素の階調を0〜Fの1桁の16進数にして変数 var に保存します。座標は1始まりです。
    • pixel var 1 1: var の値（0〜15、または0〜F）を画面のx=1、y=1に書き込みます。画素の変更はプログラムから行います。10進数の 10 は階調A、15 はFです。
    • var name world: 変数 name に値を代入します。変数が未定義でも定義でき、再定義もできます。文字列に空白がある場合は var name "hello world" のように引用符で囲みます。
    • input name input1: input1 の値を name の末尾に追加します。
    • copy name input1: input1 の値で name を置き換えます。
    • clicking-key name: 直近にクリック／押下したキーを name に保存します。
    • add input1 input2 / sub input1 input2 / imul input1 input2 / idiv input1 input2: 変数 input1 を左辺として計算結果で更新します。変数の値は整数として解釈し、16進数表記（A〜Fを含む値）にも対応します。
    • wait 100: 指定したミリ秒だけ待機します。

    空行と # で始まるコメント行は無視されます。var と display は変数を定義・更新します。参照先の変数が未定義の場合は空文字として黙って処理せず、エラーとして実行を停止します。ラベルが存在しない、割り算の除数が0、命令の引数が不正などの場合もログに表示します。
